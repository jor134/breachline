# Race car

"F1 2022 Generic Free (for @TheoDevF12)" by Posti Cloudmuziq Mästaré Formula 1 Team (https://sketchfab.com/PostiF1),
https://sketchfab.com/3d-models/f1-2022-generic-free-for-theodevf12-03a7c467b67e48ca9d0b6e9272ef0732,
CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/).

Changes for the game (tools/hq_car.py with tools/qem.c): all textures removed (with them the F1 and tyre-maker logos), the steering
wheel and glass dropped, each part recoloured to a solid colour (team paint, carbon, metal, tyre, rim) and the mesh simplified with
quadric edge collapses, which keeps the curves smooth. `car.glb` (about 80k triangles) is used for the parked cars, `car_lo.glb`
(about 20k) for the cars racing on the track. In game every team paints it its own colour.
