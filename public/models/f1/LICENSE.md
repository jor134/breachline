# Race car

"Ferrari F1 2019" by valvetin (https://sketchfab.com/valvetin), https://sketchfab.com/3d-models/ferrari-f1-2019-1b050bffe4e749b586b4782ee7ff4fd0,
CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/).

Changes for the game (tools/solid_car.py): all textures and every sponsor/brand decal removed, the cockpit details dropped, each
part recoloured to a solid colour (team paint, carbon, metal, tyre, rim) and the mesh simplified. `car.glb` (about 55k triangles)
is used for the parked cars, `car_lo.glb` (about 17k) for the cars racing on the track. In game every team paints it its own colour.

Note: the shape is still recognisably based on a real team's 2019 car. Ferrari is a trademark of Ferrari S.p.A.; no names or logos
are used in the game. Keep the project private / non-commercial, or swap in a generic car before publishing.
