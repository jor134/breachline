# Civilian models

All by Michael Constantine (https://sketchfab.com/devdesgames), downloaded from Sketchfab under CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/).
Changes for the game: textures re-encoded, specular-glossiness materials converted to metal-roughness (tools/pack_glb.py).
They come without a skeleton; the game fits one to each and poses it in code (js/chars.js). In game they are hostages and bystanders.
